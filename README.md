# ☕ DIAW

Repositório da disciplina **Desenvolvimento e Integração de Aplicações Web (DIAW)**, do curso de **Engenharia de Software** da **PUC Minas**.


## 📚 Sobre

Este repositório reúne as atividades práticas desenvolvidas ao longo da disciplina, com foco principal em **consumo, integração e desenvolvimento de APIs**.

## 🎯 Objetivo

- Praticar conceitos de desenvolvimento de aplicações web
- Explorar consumo e criação de APIs
- Consolidar o aprendizado através de exercícios práticos

## 🛠️ Tecnologias

- ☕ Java

## 🎓 Instituição

**PUC Minas** — Engenharia de Software
